## 이번 소스 반영
1. 기존 저장의 weaponEquipped=true 또는 미정(undefined)을 시각용 무기 ID 2369에 연결하고, false를 0(맨손)으로 연결한다. 무기 강화 수치 및 소유권/세이브는 변경하지 않는다.
2. 로컬 3D 렌더러의 syncLocalPlayer에 매 프레임 시각용 무기 ID 전달한다.
3. 비동기 캐릭터 GLB의 스켈레톤이 로드되기 전에 부착을 시도하지 않도록 지연한다.
4. 기존 KayKit 손 부착점 handslotr와 System G6 손 부착점 palm_R를 시도한다. G6에서 실제 무기의 회전·크기·그립 위치는 시각 검수가 필요하다.
5. 장비 시각 선택의 이전 저장 호환 단위 테스트를 추가한다.
