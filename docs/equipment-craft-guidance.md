# 모바일 제작 안내

비용이 title에만 있어 터치 환경에서 확인하기 어려웠다. 경갑/중갑 비용과 부족한 재료를 공통 레시피 두 줄에 표시한다. 부위마다 같은 비용을 반복하지 않는다.

상점 범위 밖에서는 상점 접근 안내, 재료 부족은 정확한 차액, 가능하면 제작 가능을 표시한다. 제작 불가능한 버튼은 비활성화한다. 위치가 바뀌면 자원 변화가 없어도 가용 상태를 새로 그린다. 기존 session.dispatch의 자원·거리 검증을 그대로 유지한다. 착용 버튼 title에는 현재 방어력에서 교체 후 방어력도 표시한다.

검증: 타입/빌드 성공. 인벤 기존 제작·보관·장착·해제와 새 부족재료/거리 갱신 총4테스트 성공. Chromium 실제PC1440/모바일390/320에서 비용·부족 안내 표시·불가능 제작 비활성·가로넘침 없음·JS오류0 확인. 전체CI와 게시 상태는 PR/Notion MASTER 참조.
