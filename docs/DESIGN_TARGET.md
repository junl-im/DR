# 던전 zero 최종 디자인 기준

사용자 확정: 2026-10-12. 최종 화면 완성도 목표는 **Lineage2Elbera 급**이다. 현재 로우폴리 프로토타입을 최종 디자인으로 간주하지 않는다.

- 캐릭터: 인체 비례, 의상과 갑옷 재질, 장비 외형 차이, 이동·공격·피격 애니메이션의 연결을 개선한다.
- 배경: 마을과 필드의 지형 질감, 건축 밀도, 식생, 조명과 그림자가 하나의 세계처럼 보이도록 맞춘다.
- 화면: 사용자가 선택한 고전 MMORPG 분위기·고정 대각 시점·하단 HUD를 유지한다. 이름과 체력·대상·전투 효과가 배경 위에서 읽혀야 한다.
- 아트 통일: 모델의 세부 수준·색·스케일·그림자를 통일한다. 팩 수를 늘리는 것만으로 품질 달성을 판단하지 않는다.
- 품질 확인: 동일한 마을/필드/전투 구도의 전후 캡처와 PC·모바일 성능을 함께 비교한다. 실제 측정 전 성능 달성을 주장하지 않는다.

Elbera는 품질 참고작이다. 원작 에셋 복제 허가를 의미하지 않는다. 검증된 라이선스 또는 자체 제작 자산으로 목표에 접근한다.

첫 비교 장면: 플레이어 1명·장비 외형 3종·몬스터 3종·마을 1곳·필드 1곳. 현재는 외형 개선 전이며 이 범위의 완성을 주장하지 않는다.
