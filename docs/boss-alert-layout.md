# 보스 공격 예고 HUD 겹침

실제 정예 AI 공격 예고의 DOM 위치를 측정한 결과320/390px에서 캐릭터HUD 및 의뢰 안내와 겹쳤고844px가로에서도 캐릭터HUD와 겹쳤다. 고정 top55/103px 대신 실제 캐릭터/의뢰HUD 하단+8px에 경고를 배치하고 경고 하단+8px에 회피를 배치한다. 가로화면 회피42px를44px로 보완한다.

검사는 정상 의뢰이동으로 필드에 나온 후 기존 정예 몬스터만 플레이어 가까이 옮기는 통제된 전투배치fixture다. 플레이어좌표/HP/보상/의뢰/UI클래스를 강제하지 않고 기존 AI가 생성한 실제예고의 페인트 위치를 관측한다. 일반 자연스폰 전체보스플레이라고 과장하지 않는다. PC1440/모바일320/390/가로844에서 HUD겹침없음·경고회피간격8px·회피44px·화면내위치를 확인한다.
